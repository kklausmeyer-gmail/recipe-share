# Recipe Box

Our private, ad-free family recipe collection: a photo-first grid, search by keyword or ingredient,
tags, cook mode, a cooking history with per-person star ratings and notes, the original recipe
page one tap away, a meal planner with weekly suggestions, and a grocery list you can paste into AnyList.

Only invited people can sign in, and hosting is free (GitHub Pages + Supabase free tier).
